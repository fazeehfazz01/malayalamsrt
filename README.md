# Faz SRT Translator

A mobile-friendly SRT translator focused on natural, conversational Malabar / Kozhikode Malayalam.

## Current implementation

- Upload `.srt` files from desktop or mobile.
- Choose Google Gemini or OpenAI.
- Enter your own provider API key for each translation session.
- Translate in batches of 12 subtitle entries.
- Preserve original subtitle indices and timestamp lines in the exported file.
- Preview translated Malayalam and download UTF-8 SRT.
- Translation prompt prioritizes meaning, tone, context and natural Malabar colloquial speech rather than literal/formal translation.

## Deploy to Cloudflare Pages

1. Create a GitHub repository named `malayalamsrt`.
2. Upload all files and folders from this project to the repository root.
3. In Cloudflare Dashboard, open **Workers & Pages → Create → Pages → Connect to Git**.
4. Select the `malayalamsrt` repository.
5. Framework preset: **None**.
6. Build command: leave blank.
7. Build output directory: `/` (project root).
8. Deploy. Cloudflare Pages Functions in `functions/api/translate.js` are deployed automatically.
9. The default project URL will be `https://malayalamsrt.pages.dev` only if that Pages project name is available. Otherwise choose another available Pages project name.

## Local preview / development

Install Node.js, then in the project directory:

```bash
npx wrangler pages dev .
```

The Pages Function route is `/api/translate`.

## API key handling

The UI does not store API keys in localStorage or cookies. It sends the key in the HTTPS request body to the Pages Function, which forwards it to the selected AI provider. The function does not write keys to a database. Hosting providers may have request-level operational logs; do not use this on a shared or untrusted device. Never commit API keys to GitHub.

## Important notes

- API calls can incur charges or be subject to provider quotas.
- The website cannot guarantee perfect dialect authenticity for every line. Review the preview, especially idioms, humour, profanity and culturally specific dialogue.
- Timestamp and numbering preservation is handled by the app, not generated by the AI.
- The translation is a draft-quality aid; human review is recommended before publication.
